# Hotel-Review-Parser

Сервис для сбора отзывов об отелях с сайта «Островок». Автоматически ищет отели по выбранному городу, собирает детальные оценки (чистота, расположение, цена/качество и др.) и тексты отзывов, а затем сохраняет результат в CSV-файл.

### Структура данных

| Поле        | Описание                               |
| ----------- | -------------------------------------- |
| review_id   | Уникальный идентификатор записи отзыва |
| cleanliness | Чистота                                |
| hygiene     | Средства гигиены                       |
| location    | Расположение                           |
| price       | Цена/Качество                          |
| service     | Обслуживание                           |
| room        | Номер                                  |
| food        | Питание                                |
| wifi        | Качество Wi-Fi                         |
| text        | Текст отзыва                           |

## Быстрый старт

1. Клонируйте репозиторий:

```bash
git clone https://github.com/fetgrigory/Hotel-Review-Parser.git
```

2. Создайте виртуальное окружение для изоляции зависимостей проекта:

```bash
uv venv
```

3. Активируйте виртуальное окружение:

* На Windows:

```bash
.venv\Scripts\activate
```

* На macOS и Linux:

```bash
source .venv/bin/activate
```

4. Установите зависимости:

```bash
uv sync
```

5. Запустите парсер:

```bash
uv run python -m src.main
```
