# Hotel-Review-Parser

Сервис для сбора отзывов об отелях с сайта «Островок». Автоматически находит отели в выбранном городе, извлекает оценки и тексты отзывов, обрабатывает данные и сохраняет результаты в CSV-файл.

### Структура данных

| Поле               | Описание                               |
| ------------------ | -------------------------------------- |
| `review_id`        | Уникальный идентификатор записи отзыва |
| `rating_score`     | Оценка отзыва в баллах                 |
| `rating_description` | Словесная оценка отзыва              |
| `text`             | Текст отзыва                           |

---

## Технологии

| Модуль              | Описание                                   |
| ------------------- | ------------------------------------------ |
| `selenium`          | Автоматизация браузера и извлечение данных |
| `webdriver-manager` | Управление драйверами для Selenium         |
| `emoji`             | Обработка эмодзи в тексте                  |
| `pandas`            | Обработка и очистка данных                 |

## Быстрый старт

1. Клонируйте репозиторий:

```bash
git clone https://github.com/fetgrigory/Hotel-Review-Parser.git
```

2. Создайте виртуальное окружение для изоляции зависимостей проекта:

```bash
uv venv
```

3. Активируйте виртуальное окружение:

* На Windows:

```bash
.venv\Scripts\activate
```

* На macOS и Linux:

```bash
source .venv/bin/activate
```

4. Установите зависимости:

```bash
uv sync
```

5. Запустите парсер:

```bash
uv run python -m src.main
```
